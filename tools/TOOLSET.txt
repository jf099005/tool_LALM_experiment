目前 toolset 一覽（來源：tools/tools_registry.py::available_tool_names()，2026-10-17）
====================================================================================

說明：
- 這份清單是 tools/tools_registry.py 裡「有 @register 且未被註解」的工具，也就是
  training data 生成、benchmark construct、live agent 實際會用到的那一組。
- 「必填參數」只列 required 裡的參數（不含 audio_path/output_path，由 harness 自動帶入，
  模型不需要也不應該自己填）；「選填參數」是 schema 裡其餘的 properties。
- 執行方式：「in-process」＝在呼叫端目前的 Python 直譯器內直接跑；
  「heavy (conda env)」＝由 tools/heavy_tool_pool.py 轉發到各自獨立的 conda env 執行
  （在 serve_heavy_tools() 區塊內走常駐 server，否則走一次性 subprocess）。

目前「已實作但未啟用」的工具（tools_registry.py 裡 @register 被註解掉，不在上面清單裡）：
  amplitude_normalize, loudness_normalize, remove_dc_offset, spectral_normalize,
  add_noise, pad_noise, insert_event
這些在 tools/ 底下有完整實作（normalize.py / audio_edit/editor.py），但目前不會被模型看到、
也不會出現在訓練資料或 benchmark 裡；要啟用請在 tools_registry.py 取消對應 @register 的註解。

asr（ASRTool，Whisper 語音辨識轉文字）不在這份清單裡：它在 tools/_tool_table.py 有登記、
在 apply_tools.py::TOOL_ENV 也有對應的 Whisper env，但 tools_registry.py 裡沒有
@register("asr", ...) 區塊，所以不屬於「模型可呼叫的 audio-to-audio 工具鏈」，只在其他腳本
（如 apply_tools.py）被直接呼叫。

資料來源檔案：
  tools/tools_registry.py          - 啟用清單與啟用條件 (_HAS_LIBROSA/_HAS_DEEPFILTER/_HAS_AUDIOSR/_HAS_SAM_AUDIO)
  tools/clipping.py, denoise.py, normalize.py, pitch_time.py - 輕量工具的 description()/parameter_schema()
  tools/human_voice_enhance.py, super_resolution.py, extract_remove_target.py, source_separation.py - 重量 DL 工具
  tools/_tool_table.py             - 全部已實作工具（含未啟用者）的完整目錄
